# かんたん動画つなぎ

複数の動画・写真をつなげて1本のmp4動画にする、シンプルな動画編集アプリです。
`index.html` 1ファイルで完結しており、サーバーへのアップロードなしにブラウザ内(ffmpeg.wasm)だけで動画を書き出します。

## 使い方

1. `index.html` をそのままブラウザで開くか、GitHub Pages などでホストしてスマホの Safari / Chrome からアクセスします。
2. 「ファイルを選択」から動画・写真を複数選びます(スマホのカメラロールからも選択可能)。
3. サムネイル一覧で「上へ / 下へ」ボタンや PC ならドラッグ&ドロップで順番を入れ替えられます。写真は表示秒数(デフォルト3秒)を変更できます。
4. 必要なら「BGMを追加」から音楽ファイルを1つ選び、音量や「元の音声を残す/BGMだけにする」を設定します。
5. 「プレビュー再生」で選んだ順に再生されるか確認できます。
6. 「書き出す」を押すと端末内で結合処理が行われ、完成した動画をスマホに保存(共有 / ダウンロード)できます。

## 技術メモ

- 動画処理は [ffmpeg.wasm](https://github.com/ffmpegwasm/ffmpeg.wasm) をCDN経由で読み込み、ブラウザ内(WebAssembly)で完結させています。サーバー側の処理は一切ありません。
- Safari を含むモバイルブラウザで動くよう、SharedArrayBuffer を必要としないシングルスレッド版の core を使用しています。
- 写真は Canvas で指定解像度に合わせてレターボックス変換した上で PNG 化し、`-loop 1` で動画区間に変換しています。動画はそのままの長さでリサイズ・パディングして使用します。
- つなぎ目の違和感を減らすため、各区間を同じ解像度・フレームレート(30fps)・コーデック(H.264, yuv420p)・音声フォーマット(AAC, 44.1kHz, ステレオ)に揃えています。元動画に音声がない場合は無音トラックを自動生成し、常に音声トラックがある状態にしてからつないでいます。fpsの統一は `fps` フィルタで実際に全フレームを等間隔(1/30秒間隔)に再サンプルしており、24fpsや60fpsなど元のfpsが混在していてもカクつかないことをテストで確認済みです。
- 写真には `zoompan` フィルタでごく控えめな自動ズームイン(表示時間いっぱいで1.0倍→1.12倍、中央基準)を加えており、前後の動画との「静止 vs 動き」のギャップを和らげています。
- 各クリップの代表フレームの明るさを測定し、全体平均に対して明るすぎる/暗すぎるクリップだけを `eq=brightness` で軽く補正してから結合します(補正量は上限あり、あくまで簡易補正です)。
- 区間同士は `xfade`(映像)・`acrossfade`(音声)フィルタでクロスフェード結合しています(既定0.6〜0.8秒程度、短いクリップでは自動的に短縮して破綻を防止)。映像と音声は同じオフセット計算で同期しているため、片方だけ先に切り替わることはありません。1個だけの場合はクロスフェードなしでそのまま書き出します。
- BGMは `-stream_loop -1` + 出力の長さ指定で、動画より短ければ自動ループ、長ければ自動カットしています。「音声を残す」を選んだ場合は `amix` で元の音声とBGMをミックス(音量の自動低減はオフにし、BGM音量スライダーの値がそのまま反映されるようにしています)、「BGMだけにする」を選んだ場合は音声トラックをBGMに置き換えます。
- ファイル合計サイズ(500MB、BGMも含む)・合計時間(3分)の上限を超える場合はエラーメッセージを表示します。無音で固まらないよう、処理失敗時は必ずメッセージを表示します。

## 既知の制限(叩き台としての注意点)

- BGMはアップロードした1曲のみ対応です(複数曲・フェードイン/アウトなどはありません)。
- カット編集・テロップ機能はありません(クロスフェードのみ対応)。
- 明るさ補正はごく簡易なもので、色味(色相・彩度)の補正までは行っていません。
- 写真のズームインは一律のパターンです(パン方向の選択や、写真ごとの効果の切り替えはまだありません)。
- 動画・写真あわせて6個程度までを想定したシンプルな作りです(最大12個まではUI上許容していますが、端末の性能によっては失敗する場合があります)。
- 初回書き出し時、動画エンジン(ffmpeg-core, 約30MB)のダウンロードが発生するため、通信環境によっては時間がかかります。

まずは動くものとして作成しています。改善したい点があれば相談しながら直していきましょう。
